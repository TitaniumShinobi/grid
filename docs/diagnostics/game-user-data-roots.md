# Game-owned user-data roots

Grid resolves standard per-user locations from each game's `user-data-roots.v1.json`; it does not search Documents, AppData, or user profiles. Callers provide exact known-folder anchors, and the shared resolver rejects absolute, remote, device, traversal, and escaping definition paths. A descriptor identifies locations only—it does not claim that an installation or production adapter is connected.

Skyrim Special Edition separates `Documents\My Games\Skyrim Special Edition` configuration/save state from `...\SKSE` diagnostics. INIs may be fully hashed when authorized, saves are presence-only, and SKSE collection is limited to declared top-level log patterns, including observed `crash-*.log`, with explicit file-count and byte limits. Bethesda documents the [Skyrim Special Edition save root](https://help.bethesda.net/app/answers/detail/a_id/41673/~/where-do-i-find-my-saves-for-the-elder-scrolls-v%3A-skyrim), while the SKSE project documents its [SKSE log root](https://github.com/ianpatt/skse64/blob/master/skse64_readme.txt).

The GTA descriptor records the locally observed `Documents\Rockstar Games\GTA V` variant as `ObservedLocal`; it does not promote that path to an official or connected-production claim. `Profiles` is explicitly excluded, so Story Mode saves and profile contents are never enumerated. Only declared top-level diagnostic log names are eligible for bounded reads. Rockstar separately documents its [legacy `GTAV` settings/profile root](https://support.rockstargames.com/articles/4YCEXeZHZXBkQuzdTJcqLB/rockstar-games-error-code-17) and [launcher diagnostic logs](https://support.rockstargames.com/articles/7rGZwcW07ewePNQ70Ytxe6/system-files-for-windows-pc-troubleshooting); that legacy spelling is retained as provenance rather than silently treated as an alias.

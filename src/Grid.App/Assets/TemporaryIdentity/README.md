# Temporary Stage 1 identity

`GridTemporary.ico` is a deliberately temporary application identity used only until branding is approved.

- The mark is a Windows-native Segoe UI Variable capital `G`.
- The background and border use Grid's existing neutral shell colors.
- It is shared by the executable, AppWindow, installer, and Start shortcut.
- It is not a finalized logo, type treatment, or brand asset.

Replace this isolated asset later without changing application logic or layouts.
